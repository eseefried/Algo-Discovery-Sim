## 1 Introduction

The concept of a span program as a linear-algebraic model of computation is not new. It was introduced by Karchmer and Wigderson in 1993 [9] and has many applications in classical complexity theory. Span programs can be used to evaluate decision problems. In 2008 Reichardt and Spalek [12] introduced a new complexity measure for span programs – witness size, which, as Reichardt showed later in [10, 11], has strong connection with the quantum query complexity. There is a quantum algorithm for evaluating span programs [10] and these two complexity measures are essentially equivalent. The difficulty is to come up with a span program with a good witness size complexity.

In [12] authors dealt with bounded-size span programs evaluating Boolean functions each on $O(1)$ bits and posed an open question – do there exist interesting quantum algorithms based directly on asymptotically large span program? Belovs used span programs to construct learning graphs [4, 3]. He also used span program approach for the matrix rank problem [2]. In [1] Ambainis et al. came up with a simple yet powerful span program for the graph collision problem.

In this paper, we extend the family of algorithms based on span programs. We present two new span-program-based quantum algorithms – an $O(n\sqrt{n})$ algorithm for the graph bipartiteness problem and an $O(n\sqrt{n})$ algorithm for the graph connectivity problem. Both algorithms in the quantum query sense are optimal because the witness sizes match the quantum query complexity lower bounds [6, 7] for these problems. Thus we demonstrate that span programs can be useful also for the problems with an asymptotically large input and possibly our algorithms could be building blocks for bigger span programs in the future.

The graph connectivity problem has been studied before [7] and there already exists a $O(n\sqrt{n})$ quantum query algorithm which requires $O(n)$ qubits of quantum memory. The advantage of our algorithm is that it uses only $O(\log n)$ qubits of quantum memory because the span program $P_{2}$ uses a vector space with $O(n^{2})$ dimensions. Similarly for the graph bipartiteness problem. It can be solved with the breadth-first search method [8] which uses $O(n)$ qubits of quantum memory, but our approach with a span program requires $O(\log n)$ qubits of quantum memory.

## 2 Preliminaries

In this paper, we present algorithms which work on simple graphs, given in adjacency model. If the given graph has $n$ vertices then the input size for an algorithm is $n\times n$ and we assume that the input variable $x_{i,j}$ corresponds to the value of entry in i-th row and j-th column of the adjacency matrix.

### 2.1 Span programs

**Definition 1 ([1]).**

A span program $P$ is a tuple $P=\left(H,\left|t\right\rangle,V\right)$, where $H$ is a finite-dimensional Hilbert space, $\left|t\right\rangle\in H$ is called the target vector, and $V=\{V_{i,b}|i\in[n],b\in\{0,1\}\}$, where each $V_{i,b}\subseteq H$ is a finite set of vectors.

Denote by $V(x)=\bigcup{\{V_{i,b}|i\in[n],x_{i}=b\}}$. The span program is said to compute function $f:D\rightarrow\{0,1\}$, where the domain $D\subseteq\{0,1\}^{n}$, if for all $x\in D$,

$$
f(x)=1\iff\left|t\right\rangle\in\operatorname{span}(V(x)).
$$

Basically, what this definition says is that for each input variable $x_{i}$ we have two sets of vectors (as the span program authors, we define these vectors in advance) – $V_{i,0}$ and $V_{i,1}$. If $x_{i}=b$ then we say that vectors from the set $V_{i,b}$ are available and vectors from the set $V_{i,1-b}$ are not available. If some vector is included in both sets $V_{i,0}$ and $V_{i,1}$ then we say that it is a free vector – it is always available.

The function returns $1$ iff the target vector can be expressed as a linear combination of the available vectors, otherwise it returns $0$.

**Definition 2 ([1]).**

(1) A positive witness for $x\in f^{-1}(1)$ is a vector $w=(w_{v}),v\in V(x)$, such that $\left|t\right\rangle=\sum_{v\in V(x)}{w_{v}v}$. The positive witness size is
  $$
  \operatorname{wsize}_{1}(P):=\max_{x\in f^{-1}(1)}{\min_{w:\text{witness of }x}{\|w\|^{2}}}.
  $$
(2) A negative witness for $x\in f^{-1}(0)$ is a vector $w\in H$, such that $\left\langle t|w\right\rangle=1$ and for all $v\in V(x)$: $\left\langle v|w\right\rangle=0$. The negative witness size is
  $$
  \operatorname{wsize}_{0}(P):=\max_{x\in f^{-1}(0)}{\min_{w:\text{witness of }x}{\sum_{v\in V}{{\left\langle v|w\right\rangle}^{2}}}}.
  $$
(3) The witness size of a program $P$ is
  $$
  \operatorname{wsize}(P):=\sqrt{\operatorname{wsize}_{0}(P)\cdot\operatorname{wsize}_{1}(P)}.
  $$
(4) The witness size of a function $f$ denoted by $\operatorname{wsize}(f)$ is the minimum witness size of a span program that computes $f$.

**Theorem 2.1 ([10, 11])**

$Q(f)$ and $\operatorname{wsize}(f)$ coincide up to a constant factor. That is, there exists a constant $c>1$ which does not depend on $n$ or $f$ such that $\frac{1}{c}\operatorname{wsize}(f)\leq Q(f)\leq c\cdot\operatorname{wsize}(f)$.

## 3 Span program for testing graph bipartiteness

A bipartite graph is a graph whose vertices can be divided into two disjoint sets such that there is no edge that connects vertices of the same set. An undirected graph is bipartite iff it has no odd cycles.

**Algorithm 1.**

There exists a span program $P$ which for a graph with $n$ vertices detects if the graph is bipartite with $wsize(P)=O(n\sqrt{n})$.

**Proof.**

We will make a span program which detects if a graph has an odd cycle.

Let $n=|G|$ be a number of vertices in the given graph $G$. Then the span program is as follows:

Span program $P_{1}$ for testing graph bipartiteness

- $H$ is a $(2n^{2}+1)$ dimensional vector space with basis vectors $\{\left|0\right\rangle\}\cup\{\left|v_{k,b}\right\rangle|v,k\in[1..n],b\in\{0,1\}\}$.
- The target vector is $\left|0\right\rangle$.
- For every $k\in[1..n]$ make available the free vector $\left|0\right\rangle+\left|k_{k,0}\right\rangle+\left|k_{k,1}\right\rangle$.
- For every $k\in[1..n]$, for every edge $u-v$ (where input $x_{u,v}=1$), make available the vectors $\left|u_{k,0}\right\rangle+\left|v_{k,1}\right\rangle$ and $\left|u_{k,1}\right\rangle+\left|v_{k,0}\right\rangle$.

The states in the span program $P_{1}$ are mostly in the form $\left|v_{k,b}\right\rangle$ where $v$ is vertex index, $k$ represents vertex from which we started our search for an odd length cycle and $b$ represents the parity of the current path length. The first subindex $k$ in state $\left|v_{k,b}\right\rangle$ can also be considered as the subspace index for the subspace $V_{k}=\operatorname{span}(\{\left|v_{k,b}\right\rangle|v\in[1..n],b\in\{0,1\}\})$. Vectors corresponding to edges are in the form $\left|u_{k,b}\right\rangle+\left|v_{k,1-b}\right\rangle$ consisting from sum of two states which both belong to same subspace $V_{k}$.

In the span program $P_{1}$ the target vector $\left|0\right\rangle$ can only be expressed as a linear combination of the available vectors if at least one of the vectors in the form $\left|k_{k,0}\right\rangle+\left|k_{k,1}\right\rangle$ can be expressed. Without loss of generality, if there is an odd length cycle $v_{1}-v_{2}-\dots-v_{(2j+1)}-v_{1}$ then the target vector can be expressed by taking the vectors corresponding to the edges of this cycle, alternatingly with plus and minus sign

$$
\left|0\right\rangle=\left(\left|0\right\rangle+\left|1_{1,0}\right\rangle+\left|1_{1,1}\right\rangle\right)-\left(\left|1_{1,0}\right\rangle+\left|2_{1,1}\right\rangle\right)+\dots-\left(\left|(2j+1)_{1,0}\right\rangle+\left|1_{1,1}\right\rangle\right)
$$

therefore the span program $P_{1}$ will always return $1$ when the given graph is not bipartite.

From the other side, if there is no odd length cycle then none of the vectors in the form of $\left|k_{k,0}\right\rangle+\left|k_{k,1}\right\rangle$ can be expressed using the available vectors from $P_{1}$. To cancel out the state $\left|k_{k,0}\right\rangle$ we should be using a vector $\left|k_{k,0}\right\rangle+\left|v_{k,1}\right\rangle$ corresponding to some edge $k-v$ where $v$ is some vertex adjacent to $k$ because no other vector contains the state $\left|k_{k,0}\right\rangle$. By doing so we move from the state $\left|k_{k,0}\right\rangle$ to the state $\left|v_{k,1}\right\rangle$ (possibly with some coefficient other than $1$) which has the parity bit flipped. Similarly, to cancel out the state $\left|v_{k,1}\right\rangle$ we should be using a vector corresponding to some edge going out from vertex $v$. To stop this process we need to reach the state $\left|k_{k,1}\right\rangle$. It can be done only if there is an odd cycle because the path must be closed and the parity bit restricts it to odd length. When there is no odd cycle, span program $P_{1}$ will always return $0$.

We can conclude that $P_{1}$ indeed computes the expected function. It remains to calculate the witness size of $P_{1}$.

For the case when there is an odd cycle we need to calculate the positive witness size. If there is an odd cycle $v_{1}-v_{2}-\dots-v_{d}-v_{1}$ with length $d$ then the target vector can be expressed in this way

$$
\left|0\right\rangle=1\cdot\left(\left|0\right\rangle+\left|1_{1,0}\right\rangle+\left|1_{1,1}\right\rangle\right)+(-1)\cdot\left(\left|1_{1,0}\right\rangle+\left|2_{1,1}\right\rangle\right)+\dots+(-1)\cdot\left(\left|d_{1,0}\right\rangle+\left|1_{1,1}\right\rangle\right)
$$

and the positive witness $w$ here consists only from $d+1$ entries $\pm 1$ therefore $\|w\|^{2}=d+1$.

If $v_{1}-v_{2}-\dots-v_{d}-v_{1}$ is a cycle then also $v_{2}-v_{3}-\dots-v_{d}-v_{1}-v_{2}$ is a cycle and therefore the target vector can also be expressed in this way

$$
\left|0\right\rangle=\left(\left|0\right\rangle+\left|2_{2,0}\right\rangle+\left|2_{2,1}\right\rangle\right)-\left(\left|2_{2,0}\right\rangle+\left|3_{2,1}\right\rangle\right)+\dots-\left(\left|1_{2,0}\right\rangle+\left|2_{2,1}\right\rangle\right)
$$

the same follows for all $d$ vertices in this cycle and the target vector therefore can be expressed in atleast $d$ different ways. We can combine these $d$ ways each taken with coefficient $1/d$ and then we get that the positive witness size

$$
\operatorname{wsize}_{1}(P_{1})\leq d*(1/d)^{2}*(d+1)<2 \tag{1}
$$

To estimate the negative witness size we must find a negative witness $w^{\prime}$. We derive $w^{\prime}$ by defining how it acts on basis vectors. From definition ${\left\langle w^{\prime}|0\right\rangle}=1$. For every $k$ we must have $\left\langle w^{\prime}|\left(\left|0\right\rangle+\left|k_{k,0}\right\rangle+\left|k_{k,1}\right\rangle\right)\right\rangle=0$ therefore lets pick $w^{\prime}$ in such a way that $\left\langle w^{\prime}|k_{k,0}\right\rangle=0$ and $\left\langle w^{\prime}|k_{k,1}\right\rangle=-1$. Now repeat the following steps until no changes happen:

- for every available vector $\left|u_{k,0}\right\rangle+\left|v_{k,1}\right\rangle$ if $\left\langle w^{\prime}|u_{k,0}\right\rangle$ is defined then define $\left\langle w^{\prime}|v_{k,1}\right\rangle=-\left\langle w^{\prime}|u_{k,0}\right\rangle$.
- for every available vector $\left|u_{k,1}\right\rangle+\left|v_{k,0}\right\rangle$ if $\left\langle w^{\prime}|u_{k,1}\right\rangle$ is defined then define $\left\langle w^{\prime}|v_{k,0}\right\rangle=-\left\langle w^{\prime}|u_{k,1}\right\rangle$.

For all not yet defined $\left\langle w^{\prime}|v_{k,b}\right\rangle$ define $\left\langle w^{\prime}|v_{k,b}\right\rangle=0$.

For any given vector $v$ in span program $P_{1}$ the value ${\left\langle w^{\prime}|v\right\rangle}^{2}\leq 1$. The total number of vectors does not exceed $n+n^{3}$ therefore the negative witness size is

$$
\operatorname{wsize}_{0}(P_{1})\leq 1\cdot(n+n^{3}) \tag{2}
$$

Combining positive and negative witness sizes we obtain the upper bound for witness size which also corresponds to quantum query complexity

$$
\operatorname{wsize}(P_{1})=\sqrt{\operatorname{wsize}_{0}(P_{1})\cdot\operatorname{wsize}_{1}(P_{1})}=O\left(n\sqrt{n}\right) \tag{3}
$$

∎

## 4 Span program for testing graph connectivity

A graph is said to be connected if every pair of vertices in the graph is connected. If in an undirected graph one vertex is connected to all other vertices then by transitivity the graph is connected.

**Algorithm 2.**

There exists a span program $P$ which for a graph with $n$ vertices detects if the graph is connected with $wsize(P)=O(n\sqrt{n})$.

**Proof.**

Let $n=|G|$ be a number of vertices in the given graph $G$. Then the span program is as follows:

Span program $P_{2}$ for testing graph connectivity

- $H$ is a $n^{2}-1$ dimensional vector space with basis vectors $\{\left|v_{k}\right\rangle|v\in[0..n],k\in[2..n]\}$.
- The target vector is $\left|t\right\rangle=\left|0_{2}\right\rangle+\left|0_{3}\right\rangle+\dots+\left|0_{n}\right\rangle$.
- For every $k\in[2..n]$ make available the free vector $\left|0_{k}\right\rangle+\left|1_{k}\right\rangle-\left|k_{k}\right\rangle$.
- For every $k\in[2..n]$, for every edge $u-v$ (where $u,v\in[1..n]$ and input $x_{u,v}=1$), make available the vector $\left|u_{k}\right\rangle-\left|v_{k}\right\rangle$.

If all vertices are reachable from vertex with index $1$ then the given graph is connected. Here we use Belov’s [5] span program for s-t connectivity as subroutine. This subroutine checks if in a given graph there is a path from the vertex $s$ to the vertex $t$. The span program for it has the target vector $\left|s\right\rangle-\left|t\right\rangle$ and for each edge $i-j$ (input $x_{i,j}=1$) we can use the vector $\left|i\right\rangle-\left|j\right\rangle$.

In span program $P_{2}$, by using this subroutine $n-1$ times, we check if all other vertices are connected to vertex with index $1$. We create a separate subspace $V_{k}=\operatorname{span}(\{\left|v_{k}\right\rangle|v\in[0..n]\})$ for each such subroutine call to avoid any interference between them, which is a common technique [10] how to compose span programs. The span program returns $1$ when all vertices are connected, but otherwise it returns $0$.

For the case when the given graph is connected we need to calculate the positive witness size. In each s-t subroutine the shortest path length from the vertex $s$ to the vertex $t$ can not be larger than $n-1$. Threfore each vector from the set $\left\{\left|0_{k}\right\rangle|k\in[2..n]\right\}$ requires no more than $n$ vectors to express it. There are $n-1$ such subroutines. The positive witness size is

$$
wsize_{1}(P_{2})\leq n\cdot(n-1)\leq n^{2} \tag{4}
$$

To estimate the negative witness size we must find a negative witness $w^{\prime}$. We derive $w^{\prime}$ by defining how it acts on the basis vectors. From definition ${\left\langle w^{\prime}|t\right\rangle}=1$. We need to talk about negative witness only when some vertex $v$ is not connected to vertex with index 1. Then the vertex $v$ belongs to different connected component than vertex with index 1. Lets name this connected component $C_{v}$ and let the count of vertices in this connected component be $d_{v}$. Lets pick $w^{\prime}$ in such a way that for each vertex ${v_{k}}\in{C_{v}}$ set $\left\langle w^{\prime}|0_{k}\right\rangle=1/{d_{v}}$ and for each vertex ${v_{z}}\notin{C_{v}}$ set $\left\langle w^{\prime}|0_{z}\right\rangle=0$.

For $k\in[2..n]$ we must have $\left\langle w^{\prime}|(\left|0_{k}\right\rangle+\left|1_{k}\right\rangle-\left|k_{k}\right\rangle)\right\rangle=0$ therefore set $\left\langle w^{\prime}|1_{k}\right\rangle=-\left\langle w^{\prime}|0_{k}\right\rangle$ and $\left\langle w^{\prime}|k_{k}\right\rangle=0$. Now repeat the following step until no changes happen: for every available vector $\left|u_{k}\right\rangle-\left|v_{k}\right\rangle$ if $\left\langle w^{\prime}|u_{k}\right\rangle$ is defined then define $\left\langle w^{\prime}|v_{k}\right\rangle=\left\langle w^{\prime}|u_{k}\right\rangle$. For all other not yet defined basis vectors $\left|v_{k}\right\rangle$ set $\left\langle w^{\prime}|v_{k}\right\rangle=0$.

With such negative witness $w^{\prime}$ choice the overall negative witness size will only get increased by vectors which correspond to nonexistent graph edges which connects $C_{v}$ with other connected components in graph - i.e. border edges. An edge $u-v$ is a border edge if $u\in C_{v}$ and $v\notin C_{v}$. To a border edge $u-v$ correspond the vectors $\left|u_{k}\right\rangle-\left|v_{k}\right\rangle$ where $k\in[2..n]$ but only $d_{v}$ from these vectors will have $\left\langle w^{\prime}|u_{k}\right\rangle\neq\left\langle w^{\prime}|v_{k}\right\rangle$ and each such vector increases the negative witness size by value $(1/d_{v})^{2}$. For $C_{v}$ there are at most $d_{v}\cdot(n-1)$ border edges therefore the overall negative witness size is

$$
\operatorname{wsize}_{0}(P_{2})\leq d_{v}^{2}\cdot(n-1)\cdot(1/d_{v})^{2}\leq n \tag{5}
$$

Combining the positive and negative witness sizes we obtain the upper bound for the witness size which also corresponds to the quantum query complexity

$$
\operatorname{wsize}(P_{2})=\sqrt{\operatorname{wsize}_{0}(P_{2})\cdot\operatorname{wsize}_{1}(P_{2})}=O\left(n\sqrt{n}\right) \tag{6}
$$

∎
