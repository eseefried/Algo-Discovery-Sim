In this note we study the number of quantum queries required to identify an unknown multilinear polynomial of degree d in n variables over a finite field Fq. Any bounded-error classical algorithm for this task requires Ω(nd ) queries to the polynomial. We give an exact quantum algorithm that uses O(nd-1 ) queries for constant d, which is optimal. In the case q = 2, this gives a quantum algorithm that uses O(nd-1 ) queries to identify a codeword picked from the binary Reed-Muller code of order d.
