Status: **partial**

Model: `claude-fable-5-1`

Mathematics has not been independently verified.

Simulate the time evolution e^{-iHt} of the one-dimensional quantum harmonic oscillator (QHO), H = (x^2 + p^2)/2, on an n-qubit register holding a discretized wavefunction over N = 2^n grid points, using a Trotter-Suzuki product formula in which the kinetic term is implemented via the (centered) quantum Fourier transform. The abstract's headline contribution is a refined Trotter error analysis exploiting the Lie algebra structure of {x^2, p^2, xp+px}, giving subpolynomial complexity O(exp(gamma sqrt(log(N/epsilon)))) in N/epsilon.

Scope: Scope chosen (no experiment_scope supplied): one smallest useful construction, namely a second-order Trotter-Suzuki simulation of the discretized QHO Hamiltonian on n = 3 qubits (N = 8 grid points), evolution time t = pi/2 (a quarter period, which realizes the ordinary Fourier transform up to a global phase), with r = 4 Trotter steps, starting from a discretized Gaussian ground-state-like amplitude vector, measured in the position (computational) basis. Outside scope: the paper's refined Lie-algebraic Trotter error bound and its proof, the energy-cutoff-dependent step schedule achieving the stated complexity, the eigenstate/Gaussian-state preparation method with complexity poly(log(N)/epsilon), the quartic-potential method with O~(N^{1/3+o(1)}) complexity, the general O~(N) bound for complex 1D systems, and the detailed fractional Fourier transform application beyond the single relation listed.

## Symbols

- $n$: number of qubits in the position register; domain: positive integer; instance n = 3
- $N$: number of grid points N = 2^n (in the abstract, N also denotes an energy cutoff quantum number for the simulation result; the two usages are distinguished in the abstract); domain: positive integer power of 2; instance N = 8
- $j, k$: computational-basis integer labels of position and momentum grid points, big-endian binary encoding j = sum_{l=0}^{n-1} j_l 2^{n-1-l}; domain: {0, 1, ..., N-1}
- $\Delta x$: grid spacing, chosen so that position and momentum grids have equal spacing, \Delta x = \sqrt{2\pi/N}; domain: positive real
- $x_j$: position grid value x_j = (j - N/2)\Delta x; domain: real
- $\hat X, \hat P$: discretized position and momentum operators on C^N; domain: N x N Hermitian matrices
- $F_c$: centered discrete Fourier transform (QFT conjugated by alternating-sign phases); domain: N x N unitary
- $H$: QHO Hamiltonian (continuum: (x^2+p^2)/2; discretized: (\hat X^2 + \hat P^2)/2); domain: Hermitian operator
- $t$: total evolution time; domain: real; instance t = pi/2
- $r$: number of Trotter steps; domain: positive integer; instance r = 4
- $\delta$: Trotter step size \delta = t/r; domain: positive real
- $\epsilon$: target precision of the simulation (operator or state error); domain: positive real
- $\gamma$: constant in the abstract's complexity bound; domain: positive real constant (value not given)
- $\alpha$: angle of the fractional Fourier transform; domain: real

## eq_1: QHO Hamiltonian and its Lie algebra closure

$$
H = \tfrac{1}{2}\left(\hat x^2 + \hat p^2\right), \qquad [\hat x^2, \hat p^2] = 2i(\hat x\hat p + \hat p\hat x), \quad [\hat x^2, \hat x\hat p+\hat p\hat x] = 4i\hat x^2, \quad [\hat p^2, \hat x\hat p+\hat p\hat x] = -4i\hat p^2
$$

Continuum QHO Hamiltonian (hbar = m = omega = 1) and the fact that span{x^2, p^2, xp+px} closes under commutators (sl(2,R)), which is the Lie algebra structure the abstract says its refined Trotter-Suzuki analysis exploits. The precise refined error bound is not reconstructed.

Provenance: `abstract_inferred`. The abstract names the QHO and a Lie-algebraic refinement of Trotter-Suzuki; the only closed finite-dimensional Lie algebra generated by x^2 and p^2 is the standard sl(2,R) span recalled here. The commutation relations themselves are standard background; their role in the paper's bound is inferred.

Abstract evidence: a refined analysis of the Trotter-Suzuki formula that exploits the Lie algebra structure

Equation assumptions:

- Units hbar = m = omega = 1
- The paper's refined bound uses this algebra; its explicit form is unknown

## eq_2: Discretized position and momentum operators

$$
\hat X = \sum_{j=0}^{N-1} x_j |j\rangle\langle j|,\quad x_j = \left(j - \tfrac{N}{2}\right)\Delta x,\quad \Delta x = \sqrt{\tfrac{2\pi}{N}},\qquad \hat P = F_c^{\dagger} \hat X F_c,\quad (F_c)_{kj} = \tfrac{1}{\sqrt N} e^{2\pi i (j-N/2)(k-N/2)/N}
$$

Standard N-point discretization of the QHO on a symmetric grid with equal position and momentum spacing; the momentum operator is the position operator conjugated by the centered DFT. The discretized H_N = (X^2+P^2)/2 only approximates the continuum QHO on states with bounded energy; this is an approximation, not an equality.

Provenance: `assumption`. The abstract speaks of 'discrete versions' of QHO eigenstates and 'number of points in the discretization' but does not specify the grid; this is the standard Fourier-grid construction chosen for the scoped instance.

Equation assumptions:

- Symmetric grid centered at j = N/2 with big-endian integer encoding
- Equal position/momentum spacing Delta x = sqrt(2 pi / N)
- F_c equals the standard QFT conjugated by diagonal phases (-1)^j up to a global phase

## eq_3: Second-order Trotter-Suzuki product formula

$$
e^{-iH_N t} \approx \left( e^{-i\hat X^2 \delta/4}\, F_c^{\dagger} e^{-i\hat X^2 \delta/2} F_c\, e^{-i\hat X^2 \delta/4} \right)^{r},\qquad \delta = t/r,\qquad \left\| e^{-iH_N t} - (\cdot)^r \right\| = O\!\left(\tfrac{t^3}{r^2} \|\hat X\|^2\|\hat P\|^2\right)\ \text{(generic bound)}
$$

Symmetric Strang splitting of e^{-iH_N t} into r steps, each consisting of a diagonal quadratic phase in position, a centered QFT, a diagonal quadratic phase (now acting as the kinetic term), and an inverse centered QFT. The stated error is the generic second-order bound; the paper's refined Lie-algebraic bound (which yields the subpolynomial scaling) is not reconstructed.

Provenance: `standard_background`. Trotter-Suzuki splitting of position and momentum terms with QFT-conjugated kinetic phases is the standard simulation primitive; the abstract names Trotter-Suzuki but gives no formula.

Equation assumptions:

- Second order chosen for the minimal instance; the paper may use higher-order or Lie-algebraically tailored schedules
- Error bound shown is generic, not the paper's

## eq_4: Diagonal quadratic phase on the position register

$$
e^{-i\theta \hat X^2}|j\rangle = e^{-i\theta \Delta x^2 (j - N/2)^2}|j\rangle
$$

The diagonal unitary needed in eq_3, implementable with O(n^2) controlled phase gates on the binary digits of (j - N/2) (or via a quantum arithmetic circuit computing (j-N/2)^2 into an ancilla and a phase kickback).

Provenance: `standard_background`. Exponentials of diagonal quadratic functions of the computational-basis integer are standard; expanding (j-N/2)^2 in bits gives pairwise controlled phases.

Equation assumptions:

- Direct pairwise controlled-phase decomposition is used; no ancilla arithmetic assumed in the n = 3 instance

## eq_5: Stated complexity of the QHO simulation

$$
\text{cost} = O\!\left(\exp\!\left(\gamma\sqrt{\log(N/\epsilon)}\right)\right),\qquad \gamma > 0
$$

The abstract's complexity claim for simulating the QHO to precision epsilon when the initial state has energy cutoff quantum number N; this is subpolynomial in N/epsilon. Here N is the energy cutoff, not necessarily the grid size. Exactly which resource (gate count, number of Trotter steps, queries) is counted is not stated in the abstract.

Provenance: `abstract_explicit`. Copied directly from the abstract.

Abstract evidence: the complexity of our method is $O(\exp(\gamma\sqrt{\log(N/\epsilon)}))$, where $\gamma>0$ is a constant and $N$ is the quantum number associated with an “energy cutoff” of the initial state

Equation assumptions:

- Dependence on t is suppressed in the abstract's stated bound

## eq_6: Fractional Fourier transform as QHO evolution

$$
\mathcal F_{\alpha} = e^{i\alpha/2}\, e^{-i\alpha H} = e^{-i\alpha\, a^{\dagger}a},\qquad \mathcal F_{\pi/2} = \mathcal F \ (\text{ordinary Fourier transform})
$$

The fractional Fourier transform of angle alpha is the QHO evolution for time alpha up to a global phase; the scoped instance t = pi/2 therefore approximates the ordinary (continuum) Fourier transform.

Provenance: `abstract_inferred`. The abstract states the FrFT can be formulated as QHO evolution; the explicit relation recalled here is the standard one (continuum, hbar = 1), with a = (x + ip)/sqrt(2).

Abstract evidence: the fractional Fourier transform, a generalization of the Fourier transform that is useful for signal analysis and can be formulated in terms of the evolution of the QHO

Equation assumptions:

- Continuum relation; on the discretized grid it holds only approximately for states with bounded energy

## Registers

- pos: n = 3 qubits (N = 8 grid points) qubits; Holds the discretized wavefunction amplitudes psi(x_j) in the computational basis, big-endian integer j, position x_j = (j - 4) sqrt(2 pi / 8)

## Initial state

|psi_0> = (1/Z) sum_{j=0}^{N-1} exp(-x_j^2 / 2) |j>, the normalized discretized QHO ground state (Gaussian amplitudes), with Z the normalization. Its preparation via the abstract's poly(log(N)/epsilon) method is not reconstructed; for the n = 3 instance it is assumed prepared by a generic amplitude-encoding circuit.

## Measurement

Measure the pos register in the computational basis; the outcome distribution Pr(j) approximates |psi(x_j, t)|^2 Delta x on the grid. Repeat to estimate the distribution; optionally perform a swap/overlap test against a freshly prepared |psi_0> to estimate the fidelity with the expected output.

## Classical postprocessing

Compare the empirical outcome histogram with the exactly diagonalized N = 8 reference e^{-i H_N t}|psi_0> (classically computable for this instance) to estimate the Trotter error; choose r so that the generic bound in eq_3 is below the target epsilon.

## Algorithm steps

1. Prepare the discretized Gaussian initial state |psi_0> on the pos register (generic amplitude encoding; the paper's eigenstate-preparation method is outside scope). (eq_2)
2. Set delta = t/r = (pi/2)/4 = pi/8. Repeat r = 4 times the symmetric Trotter step: apply e^{-i (delta/4) X^2} (diagonal quadratic phase); apply the centered QFT F_c (standard QFT with (-1)^j phase conjugation); apply e^{-i (delta/2) X^2}; apply F_c^dagger; apply e^{-i (delta/4) X^2}. (eq_3, eq_4, eq_2)
3. The resulting state approximates e^{-i H_N t}|psi_0>, which for t = pi/2 approximates the (fractional, alpha = pi/2) Fourier transform of psi_0 up to a global phase e^{-i pi/4}; for the Gaussian ground state the output should be approximately the input, providing a simple check. (eq_6, eq_1)
