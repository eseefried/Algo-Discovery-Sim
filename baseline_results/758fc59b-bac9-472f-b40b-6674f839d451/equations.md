# Abstract to equations

Status: **partial**

Model: `claude-fable-5-1`

Mathematics has not been independently verified.

Exact synthesis of a single-qubit unitary over the Clifford-cyclotomic gate set (Clifford group plus the z-rotation R_n = diag(1, e^{i pi/n}) for even n), outputting a gate sequence with the minimum number of R_n gates; and the characterization of exactly synthesizable unitaries as U(2) matrices with entries in Z[e^{i pi/n}, 1/2].

Scope: Scoped to the smallest nontrivial case n = 4 (Clifford+T), where the Clifford-cyclotomic gate set reduces to the Kliuchnikov–Maslov–Mosca (KMM) setting, with one tiny explicit target U = T H T. The spec defines the gate set, the ring Z[zeta_n, 1/2], the n=4 ring characterization stated in the abstract, the smallest-denominator-exponent (sde) machinery and the greedy sde-reduction loop recalled from KMM as background, and the output decomposition. Outside scope: the paper's actual generalized reduction lemma for arbitrary even n, the specific list of n for which the ring characterization holds, and the density-zero ("100% failure") theorem; none of these can be reconstructed from the abstract.

## Symbols

- $n$: positive even integer indexing the Clifford-cyclotomic gate set; instance uses n = 4; domain: 2\mathbb{Z}_{>0}
- $\zeta_n$: primitive 2n-th root of unity e^{i\pi/n}; for n = 4 written \omega = e^{i\pi/4}; domain: \mathbb{C}, |\zeta_n| = 1
- $R_n$: z-rotation by \pi/n, R_n = \mathrm{diag}(1, \zeta_n) up to global phase; R_4 = T; domain: U(2)
- $H, S$: Hadamard and phase gates generating the single-qubit Clifford group (up to global phase); domain: U(2)
- $\mathcal{C}$: single-qubit Clifford group \langle H, S \rangle modulo global phase; domain: finite subgroup of PU(2), 24 elements
- $\mathcal{G}_n$: group of exactly synthesizable unitaries generated by \mathcal{C} and R_n; domain: subgroup of U(2) (modulo global phase)
- $\mathcal{R}_n$: ring \mathbb{Z}[\zeta_n, 1/2]; domain: subring of \mathbb{C}
- $U$: input single-qubit unitary to be synthesized exactly; domain: U(2) \cap M_2(\mathcal{R}_n)
- $\mathrm{sde}(z)$: smallest denominator exponent of z with respect to \sqrt{2} (n = 4 case); domain: \mathbb{Z}_{\ge 0}
- $j_i$: exponent of T chosen in the i-th reduction step; domain: \{0,1,2,3\}
- $m$: number of sde-reduction steps performed; domain: \mathbb{Z}_{\ge 0}
- $\tau(U)$: R_n-count (T-count for n = 4) of the output decomposition; domain: \mathbb{Z}_{\ge 0}

## eq_1: Clifford-cyclotomic gate set

$$
R_n = \begin{pmatrix} 1 & 0 \\ 0 & e^{i\pi/n} \end{pmatrix}, \qquad \mathcal{G}_n = \langle H, S, R_n \rangle, \qquad R_4 = T
$$

The generating set is the Clifford group (H, S) together with a z-rotation by pi/n; for n = 4 this is Clifford+T. Global phases are ignored.

Provenance: `abstract_inferred`. Abstract names the gate set; the explicit diag(1, e^{i pi/n}) matrix is the standard representation of a z-rotation by pi/n modulo global phase (the paper could equally use diag(e^{-i pi/2n}, e^{i pi/2n})).

Abstract evidence: the “Clifford-cyclotomic” gate set consisting of the Clifford group plus a $z$-rotation by $\frac{\pi}{n}$

Equation assumptions:

- Global phase ignored, so the two conventions for the z-rotation coincide
- Clifford group generated by H and S

## eq_2: Cyclotomic ring with 1/2 adjoined

$$
\zeta_n = e^{i\pi/n}, \qquad \mathcal{R}_n = \mathbb{Z}[\zeta_n, 1/2] = \Big\{ \tfrac{1}{2^k} \sum_{j=0}^{n-1} a_j \zeta_n^{\,j} : a_j \in \mathbb{Z},\ k \in \mathbb{Z}_{\ge 0} \Big\}
$$

Ring over which entries of candidate exactly-synthesizable unitaries live. For n = 4, R_4 = Z[omega, 1/2] contains 1/sqrt(2) since sqrt(2) = omega + omega^{-1}.

Provenance: `abstract_explicit`. Abstract states the ring explicitly; the expansion as integer combinations of powers of zeta_n divided by powers of 2 is the definition of adjoining zeta_n and 1/2 to Z.

Abstract evidence: the group of unitaries with entries over the ring $\mathbb{Z}[e^{i\frac{\pi}{n}},1/2]$

## eq_3: Ring characterization for n = 4 (Clifford+T)

$$
\mathcal{G}_4 = \{ U \in U(2) : U_{ab} \in \mathbb{Z}[\omega, 1/2] \ \forall a,b \} \quad (\text{modulo global phase}), \qquad \omega = e^{i\pi/4}
$$

A single-qubit unitary is exactly synthesizable over Clifford+T iff all its entries lie in Z[omega,1/2]. The abstract states this holds for n = 4 and only for a density-zero set of other even n.

Provenance: `abstract_explicit`. Directly stated in the abstract for n = 4; equality is modulo global phase (the precise phase/determinant convention of the paper is not available).

Abstract evidence: For the Clifford+T case $n=4$ the group of exactly synthesizable unitaries was shown to be equal to the group of unitaries with entries over the ring

Equation assumptions:

- Equality taken modulo global phase e^{i k pi/4}

## eq_4: Smallest denominator exponent (n = 4)

$$
\mathrm{sde}(z) = \min\{ k \in \mathbb{Z}_{\ge 0} : (\sqrt{2})^{k} z \in \mathbb{Z}[\omega] \}, \qquad \mathrm{sde}(U) := \mathrm{sde}(U_{00}) = \mathrm{sde}(U_{ab}) \ \text{for all entries of a unitary } U
$$

Complexity measure driving the KMM algorithm; for a unitary with entries in Z[omega,1/2] all entries share the same sde because |U_00|^2 + |U_10|^2 = 1.

Provenance: `standard_background`. Recalled from the KMM exact-synthesis algorithm for Clifford+T, which the abstract says is being generalized; not evidence of the paper's generalized measure for n != 4.

Equation assumptions:

- n = 4 so that sqrt(2) in Z[omega] is the relevant prime

## eq_5: Greedy sde-reduction step (KMM, n = 4)

$$
\mathrm{sde}(U) = k \ge 4 \ \Rightarrow\ \exists!\, j \in \{0,1,2,3\}: \ \mathrm{sde}(H\, T^{j}\, U) = k - 1
$$

Each iteration left-multiplies by H T^j with the unique j that lowers the sde by exactly one; iterate until sde(U) <= 3, where a finite lookup table of Clifford+T elements is used.

Provenance: `standard_background`. Recalled statement of the core lemma of the KMM algorithm; the threshold constant and uniqueness are from memory and should be checked against the source. The paper's analogue for general even n (which R_n powers and which Clifford elements reduce the generalized denominator exponent) is unknown from the abstract.

Equation assumptions:

- n = 4
- Base-case table for sde(U) <= 3 is finite and available

## eq_6: Output decomposition and R_n-count

$$
U = \big( T^{j_1} H \big)\big( T^{j_2} H \big) \cdots \big( T^{j_m} H \big)\, C, \quad C \in \mathcal{G}_4,\ \mathrm{sde}(C) \le 3, \qquad \tau(U) = \#\{ i : j_i \text{ odd} \} + \tau(C), \qquad \tau(U) = \min_{\text{decompositions of } U} \#\text{T gates}
$$

After m reductions one has H T^{j_m} ... H T^{j_1} U = C; inverting gives the circuit (using H^{-1} = H and (T^j)^{-1} = T^{-j} = Clifford · T^{j mod 2}). Only odd j contribute a T gate since T^2 = S is Clifford. The last equality (optimality) is the abstract's claim about the algorithm's output.

Provenance: `abstract_inferred`. The product form follows from inverting the reduction steps of eq_5; the minimality of the count is stated in the abstract (for general n, here specialized to n = 4). The formula for tau in terms of odd j_i assumes T^2 is absorbed into Cliffords.

Abstract evidence: We present an efficient exact synthesis algorithm which outputs a decomposition using the minimum number of $\frac{\pi}{n}$ $z$-rotations.

Equation assumptions:

- Counting is modulo Cliffords: T^{2} = S and T^{3} = S T are counted as 0 and 1 T gates respectively
- Base-case T-count tau(C) is read from the finite table

## eq_7: Tiny instance target (n = 4)

$$
U_{\mathrm{inst}} = T H T = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & \omega \\ \omega & -\omega^{2} \end{pmatrix}, \qquad \mathrm{sde}(U_{\mathrm{inst}}) = 1
$$

A concrete input with entries in Z[omega,1/2] and sde 1, so it falls into the base-case table; the algorithm should return a decomposition with at most 2 T gates (the exact minimal count is not verified here).

Provenance: `assumption`. Chosen as a minimal explicit test instance; the matrix is obtained by direct multiplication of T = diag(1, omega), H, T.

Equation assumptions:

- n = 4
- Expected output T-count <= 2; minimality not verified

## Registers

- q: 1 qubits; Single qubit on which the synthesized Clifford+R_n circuit acts (the synthesis itself is a classical algorithm; this register is only needed to execute or verify the output circuit)

## Initial state

Not part of the algorithm (the synthesis is classical). For optional verification of the output circuit, prepare |0> on q and compare the circuit's action with U_inst.

## Classical postprocessing

The entire procedure is classical: exact ring arithmetic in Z[omega,1/2], sde computation, greedy reduction, table lookup, and emission of the gate sequence with its R_n (T) count. Optional verification multiplies the output gate matrices and checks equality with U up to global phase.

## Algorithm steps

1. Input validation: check U is unitary and every entry lies in Z[omega,1/2] (eq_2, eq_3); reject otherwise since U is then not exactly synthesizable for n = 4. (eq_2, eq_3)
2. Compute k = sde(U) from the top-left entry. (eq_4)
3. While sde(U) >= 4: find the unique j in {0,1,2,3} with sde(H T^j U) = sde(U) - 1, record j, and set U <- H T^j U. (eq_5)
4. Base case: when sde(U) <= 3, look up the remaining element C in a finite table of Clifford+T unitaries with their T-optimal circuits. (eq_6)
5. Assemble the output circuit by inverting the recorded steps, U = (T^{j_1} H) ... (T^{j_m} H) C, and report the T-count tau(U). (eq_6)
6. Run the instance U_inst = T H T (sde 1, base case) and compare the returned circuit to the input matrix up to global phase. (eq_7, eq_6)
